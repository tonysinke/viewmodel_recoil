# Changelog

## v3.0.1 — 文档与实现对齐（`auto/`）

只改文档、配置注释与一处判定逻辑，**v2.x 一行未改**，定位算法本身未动。

### 修复
- **`requireUniqueReference` 之前是死开关**：配置解析会打印它，但代码固定按 `Refs == 1` 判定，关掉它毫无作用。
  现在真实生效：`true` = 恰好 1 条 `movss` 引用；`false` = 放宽为 ≥1 条。
- 单候选但结构闸门没过时，日志文案原来一律写"指纹不唯一"（与事实不符），改为区分两种情况：
  "值指纹唯一命中，但读到它的 movss 有 N 条" / "值指纹唯一命中，但没有任何 movss 读它"，并给出对应处理建议。
- 文档里"取值 `[0,1]`，中间值按比例缩放"的说法与实现不符：实现只有开 / 关两态
  （`≥ 0.5` 写 `onValue`，`< 0.5` 写 `offValue`）。README、`auto/README.md`、`examples/vmrecoil.cfg` 三处已改正。
- `vmrecoil_auto.json` 示例里的 `pattern` 写了 `48 89 5C 24 08 ...`（含 `...`，不是合法 pattern，且两条完全相同），
  已替换为真实内置默认值。
- 文档里"v3 里一个地址都没有"这句措辞过头（配置里仍有 `baselineRva` 字段）。已改为"常量定位不含任何硬编码地址"，
  并注明 `baselineRva` 只用于日志显示 RVA 差值。
- 故障排查表"指纹不唯一"一行原来只对应"多候选"这一种情况，与代码实际日志对不上，已拆成三条分别指引。

### 其他
- `.gitignore` 补上 v3 首次运行生成的 `vmrecoil_auto.json`、`vmrecoil_auto_user.cfg`（之前只忽略了 v2 的 `vmrecoil_user.cfg`）。

## v3.0.0 — 长期做法版（`auto/`）

与根目录 `src/`（v2.x）**并存**的另一个实现，功能等价，定位方式换成"不需要每版重编译"的做法。
**v2.x 一行未改。**

### 新增
- `auto/src/` — `VMRecoilAuto`：
  - 常量定位改为 **`0.325f` 值指纹（扫描全部可读节）+ `movss` RIP 引用反查**，代码中零硬编码地址；
  - cvar 注册三件套（`refinit` / `regcore` / `getfloat`）签名外部化到 `vmrecoil_auto.json`，失效改配置即可，免重编译；
  - `getfloat` 降级为 optional：不唯一时自动改用 CounterStrikeSharp `ConVar.Find()` 通道；
  - 定位结果写入状态文件，热重载时先验值再复用；
  - 安全闸门：值不匹配 / 常量不唯一 / 引用不唯一 → 空转，一个字节都不写。
- `auto/test/LocatorTest` — 离线自检工具，**不装游戏**即可用真实 `client.dll` 复现定位结果。
- `docs/VERIFICATION.md` — 定位算法验证报告（含 1.40.4.5 与 1.41.9.x 两版实测数据与复现步骤）。
- `auto/README.md` — 长期做法版完整说明：原理 / 配置项逐条 / 故障排查表 / 签名失效自救步骤。

### 验证
- 1.40.4.5：值指纹唯一命中 `0x12E11BC`，movss 引用 1 条，`refinit`/`regcore` 签名唯一 → PASS
- 1.41.9.x：值指纹唯一命中 `0x1D12A38`，movss 引用 1 条，`refinit`/`regcore` 签名唯一 → PASS
- 两版算法零改动、零参数调整，结果均与实机已知地址一致。

## v2.4.0

基于 v2.3.0 的静态审查（12 项缺陷）改造。

### 修复
- **P0** 删除探针的"自检写入 0 再写回 1"，探针改为纯只读 —— 原实现会覆盖用户已设的 OFF 状态。
- **P0** 新增 `Unload`：卸载 / 重载时把常量恢复为 `0.325f` —— 原实现 OFF 状态下卸载会让后坐力永久失效。
- **P1** `Apply` 写入后回读校验，不一致重试一次，仍失败则不更新内部 state（原实现盲更新）。
- **P1** `Locate` 三重校验：RVA 直读必须为 `0.325f`；否则必须由签名扫描反算出同一地址才采信；`0.0f` 不再单独采信（避免把上次会话遗留值当原值）。
- **P1** `VirtualProtect` 改为整页保护 + `finally` 还原，规避 4 字节写入跨页导致保护还原不完整。
- `Load` 全流程包 `try/catch`，异常时插件安全空转，不改动任何内存。
- `Poll` 读不到值不再静默：连续 NaN 计数告警 + 句柄刷新。
- 轮询逻辑改为"以 cvar 为唯一真值"，每次比对常量与期望值，漂移自愈；心跳与变化日志降噪。

### 新增
- 参数自动保存：用户改动 cvar 后落盘 `vmrecoil_user.cfg`，重开 / 换图 / 重载自动读回并写回。

### 说明
- cvar 注册使用 3 块非托管内存（ref / name / help/desc），被引擎 cvar 表长期引用，
  故意不 `FreeHGlobal`（释放会造成 cvar 表悬挂指针 → 崩溃），进程级常驻，体量几十字节。
